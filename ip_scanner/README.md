# IP Scanner

See your home network from inside Home Assistant: discovered devices, device names,
apparently available IPv4 addresses, continuous ranges and an interactive address map.

Hebrew interface with search, custom names, saved history and CSV export.
Works through Home Assistant Ingress. Supports amd64 and aarch64.

Experimental release: validate discovery and Ingress on your Home Assistant OS host.
An unanswered address is not proof that it is available or unreserved in DHCP.

Read [DOCS.md](DOCS.md) for configuration and troubleshooting.
